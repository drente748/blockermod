# الاختبارات اليدوية

هذه الاختبارات تحتاج جهازًا حقيقيًا ولا يمكن أتمتتها بالكامل. كل مجموعة تحمل حالة حالية:
`NOT RUN` يعني أنها لم تُنفَّذ بعد على جهاز.

**قبل البدء:** ثبّت نسخة `debug` (`./gradlew :app:installDebug`)، وافتح التطبيق، ثم ابدأ النفق من
الشاشة (شاشة البدء ليست ضمن هذه المرحلة، فابدأ الخدمة يدويًا عبر `adb shell am start-foreground-service`
أو من خلال أيقونة تفضيلية) وسجّل ما يلي: نوع الجهاز، إصدار أندرويد، الشبكة المستخدمة (Wi-Fi أو
بيانات الجوال).

## حدود معروفة (Known limits)

| الحد | الأثر | المتابعة |
|---|---|---|
| DoH/QUIC على 443 يتجاوز الحظر | لا يمكن تمييزه عن HTTPS/HTTP3 العادي دون MITM | قوائم عناوين الحلّالات + DoT/DoQ 853 + خيار QUIC اختياري؛ لا ادعاء بالكمال |
| ECH يخفي الاسم الحقيقي | الاسم الظاهر public_name ليس الوجهة | يُسجَّل كحالة `ECH`؛ لا MITM ولا فك تشفير — بقعة عمياء موثّقة |
| IPv6 في Full Tunnel | فشل مغلق، قد ينقطع على IPv6-only | دعم IPv6 كامل يتطلب محلّلات/rutas/ICMPv6/checksums (مؤجَّل) |
| TCP Relay ليس مكدس TCP كامل | لا إعادة إرسال/تحكّم ازدحام/TIME-WAIT | DNS-over-TCP مضمون محليًا؛ TCP العام best-effort في الوضع التجريبي |
| مسارات CIDR غير مدعومة | الحظر على مستوى أسماء النطاقات فقط | تقييم في موجة لاحقة |
| واجهة بسيطة بلا ثيم | التشغيل ممكن من الشاشة؛ التصميم/الثيم مؤجّل | مرحلة لاحقة |
| القائمة حقيقية لكنها من مصدر واحد | حجب إباحي/إعلاني يعمل؛ تغطية محدودة بمصدر StevenBlack | إضافة مصادر بتراخيص محسومة في `docs/LICENSE_DECISIONS.md` |
| قوائم الحظر تُحدَّث مع إصدار جديد فقط | لا تحديث تلقائي | قرار توزيع معلن |
| `STRICT_RESOLVER_IPS` مفعّل للحلّالات المعروفة فقط | DoH إلى عناوين عشوائية أو Private DNS بمضيف مخصّص يتجاوز الحجب | Device Owner اختياري (مؤجّل) أو تحذير للمستخدم |
