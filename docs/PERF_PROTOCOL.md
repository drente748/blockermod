# بروتوكول القياس

هذا المستند يعرّف كيف يُقاس أداء محرك الحجب: كم يستهلك من البطارية، وكم يستغرق.lookup، وكيف
يتصرّف تحت حمل DNS كثيف. الأداة المرافقة هي `tools/perf-measure.sh`.

**مبدأ القياس:** القياس على **جهاز حقيقي** (لا محاكي). المحاكي يُستخدم للتحقق الوظيفي فقط، لأن
أرقام البطارية فيه مُحاكاة ولا معنى لها.

---

## 1. الأهداف

| المقياس | الهدف | ملاحظة |
|---|---|---|
| استهلاك البطارية في الخمول (24 ساعة) | **أقل من 2%** | مرجع تنافسي معروف |
| زمن الـ lookup (p99) | يُسجَّل ويُقارن بالهدف المحدد في الموجة | القياس من داخل الجهاز لا من المضيف |
| استهلاك الذاكرة | مستقر، بلا نمو مع الزمن | يُقرأ من `dumpsys meminfo` |
| استهلاك المعالج تحت حمل 1000 استعلام | يُسجَّل ويُقارن | `dumpsys cpuinfo` و`top` |

## 2. preparatory steps

```bash
# المحاكي أو الجهاز متصل
adb devices

# تثبيت نسخة القياس
./gradlew :app:installDebug

# منح موافقة VPN تلقائيًا (جهاز الاختبار فقط)
adb shell appops set com.blockermod ACTIVATE_VPN allow

# تشغيل المحرك
adb shell am start-foreground-service -n com.blockermod/.platform.vpn.BlockerVpnService
```

## 3. القياسات

### 3.1 الخمول (24 ساعة)

```bash
tools/perf-measure.sh idle --window 86400
```

- يجبر الجهاز على الخمول: `adb shell dumpsys deviceidle force-idle`.
- يسجّل مستوى البطارية في البداية والنهاية ويحسب الفرق.
- **شرط النتيجة:** أقل من 2% خلال 24 ساعة.
- ملاحظات لازمة: الجهاز على الشحن (أو بسرعة شحن ثابتة)، والشاشة مطفأة، والشبكة مستقرة، ولا
  تطبيقات أخرى في الخلفية.

### 3.2 زمن الـ lookup (p99)

```bash
tools/perf-measure.sh latency
```

- يرسل 100 استعلام من داخل الجهاز (`nslookup` عبر الصدفة) ويقيس الزمن بالوقت الرتيب **داخل
  الجهاز** حتى لا يدخل زمن adb في القياس.
- تُحسب القيم: min، p50، p95، p99، max بالمللي ثانية.

### 3.3 حمل DNS كثيف (1000 استعلام)

```bash
tools/perf-measure.sh load --queries 1000
```

- يرسل 1000 استعلام متتاليًا ثم يلتقط `dumpsys meminfo com.blockermod` و`top` و`dumpsys cpuinfo`.
- **ما يُرصد:** نمو الذاكرة (يجب ألّا ينمو مع عدد الاستعلامات)، ونسبة المعالج أثناء الحمل، وعدد
  الاستعلامات المُهملة عند تجاوز طابور الانتظار (1024).

## 4. نتائج آخر قياس

| المقياس | النتيجة | الحالة | ملاحظة |
|---|---|---|---|
| خمول 24 ساعة | — | NOT RUN | يحتاج جهازًا حقيقيًا وشحنًا ثابتًا |
| p99 lookup | — | NOT RUN | كما أعلاه |
| حمل 1000 استعلام | — | NOT RUN | كما أعلاه |

## 5. حدود القياس المعروفة

- المحاكي: أرقام البطارية مُحاكاة، و`idle` لا يعكس سلوك جهاز حقيقي ⇒ لا يُستخدم للأرقام.
- زمن adb: أي قياس يُنفَّذ من المضيف يشمل زمن نقل الأوامر ⇒ القياس داخل الجهاز فقط.
- تغيّر شبكة الجوال: قياس تحت شبكة متنقلة يتضمّن زمن التجوال ⇒ يُسجَّل نوع الشبكة مع كل قياس.
- الخمول على شاشة مضاءة أو مع تطبيقات في الخلفية يُفسد النتيجة.
- إصدارات أندرويد المختلفة تعطي أرقامًا مختلفة ⇒ يُسجَّل إصدار النظام مع كل قياس.
